## 接线方案（经济档为主，标准档兼容）

```
                    ESP8266 (ESP-01S)            STM32F103C8T6
                    ┌──────────────┐              ┌────────────┐
         3.3V ─────┤ VCC  (3.3V)  │              │            │
         GND  ─────┤ GND          │              │  3V3 ──────┤ (3.3V 输出)
        3.3V ─────┤ CH_PD(EN)    │              │            │
                    │              │              │  PA9/TX1 ──┼──► RX  (ESP8266)
                    │  TXD ────────┼──► PA10/RX1 │            │
                    │  RXD ◄───────┼── PA9/TX1   │  PA2/TX2 ──┼──► USB-TTL RX (PC)
                    └──────────────┘              │  PA3/RX2 ◄─┼── USB-TTL TX
                                                  └────────────┘
```

| 引脚 | 接法 | 注意 |
|---|---|---|
| ESP8266 VCC | STM32 3.3V（或独立 AMS1117-3.3） | ESP8266 峰值 300mA+，不建议直接吃板载 3.3V |
| ESP8266 GND | STM32 GND | 必须共地 |
| ESP8266 CH_PD | 3.3V | 不拉高模块不工作 |
| ESP8266 TXD | STM32 PA10（USART1_RX） | 模块发→MCU 收 |
| ESP8266 RXD | STM32 PA9（USART1_TX） | MCU 发→模块收 |
| STM32 PA2/PA3 | USB-TTL → PC | USART2 调试输出，115200 |

调试输出格式（绘图脚本 tools/serial_wifi_plot.py 直接解析）：

```
[00] ch=6  rssi=-52 enc=3 ssid=Paul-Home-2.4G
```

enc: 0=开放 1=WEP 2=WPA 3=WPA2 4=WPA/WPA2

## 启动步骤

1. 按上表接线，USART2 接 USB-TTL 到电脑；
2. STM32CubeMX 打开 `stm32_project/wifi_scan_sim.ioc`，生成代码；
3. 把 `Core/Src/main.c` 与 `ap_parser.c/h` 放入工程，编译下载；
4. 电脑串口助手 115200 观察输出；或用 `python3 tools/serial_wifi_plot.py --port /dev/tty.usbserial-XXXX` 实时绘图。
